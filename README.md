Coding Moms — Daily Hustle Checklist
A simple, elegant to-do list web app built with HTML and CSS. Designed for work-from-home moms who are learning to code while juggling family life — because every checked task is a win!

 Features
 Interactive to-do list with checkboxes

 Helpful resource links that open in a new tab

 Stylish link states: hover, focus, visited, and active

💬 Motivational quote to keep the hustle going

 Clean, minimal, mobile-friendly design

📚 User Stories
The app contains four tasks wrapped in a <ul class="todo-list">

Each task includes a checkbox, a label, and a nested list with a link

Links change style on hover, focus, click, and after visiting

Links do not have underlines by default

Custom colors and outlines are applied for visual feedback

🛠️ Tech Stack
HTML5

CSS3

No JavaScript (purely style-focused)
